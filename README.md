# EvSVSR Project Page

Project page for:

**Event-Guided Stereo Video Super-Resolution**

Hanyu Xuan, Youtao Yao, Cheng Zhao, Kun Li, Xin Du, Fei Wang, Zhiliang Wu

The page is adapted from the Nerfies GitHub Pages template and includes:

- looping video demos on DSEC and SVSR-Set, and abstract;
- framework overview (EGTE + CVTI);
- quantitative results (Table 1) and visual comparisons on the real-world DSEC and the synthetic SVSR-Set;
- conclusion and BibTeX.
